# UX language

These words mean one thing in the product.

| Term | Meaning |
| --- | --- |
| Not configured | The workspace cannot offer this channel yet. |
| Ready to connect | The channel can be connected. No account, mailbox, or number is stored. |
| Connecting | A connection is in progress. |
| Connected | An account, mailbox, or number is stored for this business. |
| Syncing | VIGIE is importing from a connected channel. |
| Needs attention | A connection exists or was attempted, and the user needs to act. |
| Disconnect | Remove the stored connection. |
| Sync now | Import recent mail from a connected mailbox. |

Do not show "Available" for a channel that is only configured, and do not show "Connected" because setup exists. A connected mailbox is "Connected", with the mailbox address.

Environment variables, client secrets, and OAuth details stay in deployment docs. The product explains what the person can do next.
